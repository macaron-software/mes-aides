# UX Laws Skill

Ref: https://lawsofux.com/

## COGNITIVE

| Law | Key Rule |
|-----|----------|
| Miller's (7±2) | Chunk into groups of ~7 items |
| Hick's Law | Decision time = a + b·log2(n) — limit choices |
| Cognitive Load | Minimize extraneous load |
| Chunking | Group related info meaningfully |
| Working Memory | Don't require memorization across screens |
| Choice Overload | Too many options → paralysis |

## VISUAL (Gestalt)

| Law | Key Rule |
|-----|----------|
| Proximity | Near objects = grouped |
| Similarity | Same style = same group |
| Common Region | Shared boundary = group |
| Prägnanz | Brain prefers simplest interpretation |

## INTERACTION

| Law | Key Rule |
|-----|----------|
| Fitts's | T = a + b·log2(D/W+1) — large, close targets |
| Doherty (<400ms) | Response <400ms or flow breaks |
| Flow State | Balance challenge/skill, clear goals, feedback |
| Goal-Gradient | Motivation ↑ near goal |

## BEHAVIOR

| Law | Key Rule |
|-----|----------|
| Peak-End | Experience judged by peak + ending |
| Von Restorff | Different item remembered |
| Serial Position | First/last remembered best |
| Zeigarnik | Incomplete tasks remembered |

## CHECKLIST

```
□ Nav follows Jakob's Law (familiar patterns)
□ Options limited per Hick's Law (5-7 max)
□ Info chunked per Miller's Law
□ Touch targets ≥44px
□ Response <400ms
□ Progress shown
□ Important items first/last
□ CTAs visually distinct
□ Related items grouped
□ Complexity handled by system
```
